# Интерактивный каталог товаров (E-commerce)

Одностраничное веб-приложение каталога товаров для домашнего колбасирования с возможностью фильтрации по категориям и мгновенным поиском.

## 🛠 Стек технологий:

- HTML5 (семантическая верстка)
- CSS3 (CSS Variables, Flexbox, CSS Grid)
- Vanilla JavaScript (ES6+, работа с DOM, методы массивов `filter`, `forEach`)

## 🚀 Реализованный функционал:

- **Динамический рендеринг**: карточки товаров генерируются из массива объектов с помощью JavaScript.
- **Фильтрация по категориям**: быстрое переключение между разделами («Все товары», «Оболочки», «Специи», «Оборудование»).
- **Живой поиск**: мгновенная фильтрация списка при вводе текста без перезагрузки страницы.
- **Комбинированный фильтр**: поиск работает внутри выбранной категории.
- **Адаптивная верстка**: сетка на CSS Grid корректно отображается на ПК, планшетах и смартфонах.
